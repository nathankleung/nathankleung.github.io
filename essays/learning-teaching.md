How can we gain the most from learning and teaching programming?


## Learning
From my experiences as a beginner programmer and student learning how to code from block coding, to dabbling in web dev with HTML, CSS, Javascript, to Python, to Java, to C, to C++, to and Javascript/Typescript, I believe that there is plenty of value to be had by experiencing all these programming languages. Acquiring a breadth of experience with various languages allows for connections to be made for programming concepts between languages with how data structures work between languages and how the programs interact with the machine allows for a deeper understanding of programming as a whole.

During my ICS 212: Program Structure class, learning about C, C++, and the way the machine communicates with compiling, the input buffer, memory addresses, and program tracing have greatly benefitted my understanding of programming since the inner workings of these systems are able to be applied to other programming languages as well even if they have more functionality or obscure these aspects.


## Teaching

As part of my ICS 390: Computing Ethics for Lab Assistants class, I am the Assistant Teaching Assistant (ATA) for the lower division ICS 111: Intro to Computer Science I class. Based off of my past experience with the course and my knowledge of C and C++, I am able to better assist students and explain concepts such as the input buffer, buffer sanitation, and similar concepts that are normally hand-waved away at this level  despite the students running into problems from these issues. 

Through teaching, I am also able to refresh my understanding of fundamental programming concepts as well as reinforce connections between what I know from different programming languages. I enjoy being able to assist people and I hope that these students are able to find succeed and find something that interests them in computer science.


## Conclusion

The cycle of learning and teaching go hand in hand and by engaging with a large breadth and making connections with what we learn, it can be applied more effectively in not only our own understanding but also in the ability of sharing this knowledge with others through teaching. Communicating these concepts and ideas in an understandable way helps to better understand the material by being able to simplify but still retain substance in taught material which is beneficial for the understanding of both the one teaching and the ones being taught. The main idea is that effectively diversifying the learning of programming such as across multiple languages and teaching programming can be greatly beneficial to developing skills in programming and approaching computer science from more perspectives can provide new insights.
