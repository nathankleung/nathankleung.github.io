What type of person is suited for typescript and how do I think typescript suits me?

## My experience with Typescript
As someone who has almost zero experience with Javascript, much less Typescript, before taking ICS 314: Software Engineering, I would say that using Typescript is a tad more tedious than regular Javascript which also needs some adjusting to. It helps that I have experience with Java, C, and C++ from previous courses so I’m not a complete newbie to programming, but there are some points of friction that come from the little differences in syntax despite many similarities to Java. The presence of certain functionality like easy dynamic arrays that come with what are essentially push, pop, queue functions that work on regular arrays are very useful. 

On the other hand, the lack of certain primitive types such as int, floats, and such being bundled into the number type makes initializing these variables easy but can run into more work when it comes to processing or formatting these numbers. As well as the string type being lower case being a point of confusion early on in the learning process. 

However, I do see the advantages of Typescript in ensuring what types get passed such that the correctness of the program is more clear, even if I don't follow all of these procedures and let it infer a lot of my return types. 

## Typescript fof software engineering

For software engineering, having type security makes the design process slightly more difficult, but it makes up for it in not having to deal with messy mismatched types that can arise from normal Javascript or even as a point of confusion in other programming languages, ultimately saving time and preventing future headaches. 

## Athletic software engineering for learning

I think that the athletic software engineering approach has value as it really tests the practical skills of problem solving and technical knowledge for solving the problem, but also the time pressure can prepare people for future coding interviews that operate under similar conditions. Even though the practice WODs/quizzes are stressful, especially when there isn't enough time to finalize the solution. 

However, it is exactly this discomfort that can push improvement and shed light on what needs to be done to improve in order to be better for the future. 

Having done a few of the quizzes thus far, I think that I've somewhat gotten the hang of it and have gained from them in showing what ways my approach to the problem works and the ways it does not.
